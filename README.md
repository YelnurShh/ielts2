# IELTS Writing Mastery

Қазақ тіліндегі мектеп оқушыларына арналған IELTS Writing Task 2 платформасы.
React + TypeScript + Vite, Firebase Authentication және Cloud Firestore. Vercel-ге арналған SPA конфигурациясы дайын. Sites-ке жарияланбады.

## Іске қосу

Node.js 22 LTS немесе одан жаңа нұсқа.

```sh
npm ci
npm run dev
npm run build
```

`dist/` — production нәтижесі. Vercel: Framework = Vite, Build = `npm run build`, Output = `dist`. `vercel.json` жеке беттерге тікелей кіруді қолдайды.

## Firebase-ті іске қосу — міндетті

Конфигурация `src/firebase.ts` ішінде берілген жобаға қосылған. Firebase web API key — клиенттік конфигурация, ол әкімші құпия кілті емес. Қолжетімділікті Firestore rules басқарады. Admin SDK немесе service-account кілтін браузерге қоспаңыз.

1. Firebase Console → `ieltsplatform-ee25e` → Authentication → Sign-in method: **Email/Password** және **Google** тәсілдерін қосыңыз. Google үшін support email таңдаңыз.
2. Authentication → Settings → Authorized domains: Vercel доменіңізді және жергілікті тест үшін `localhost`, `127.0.0.1` қосыңыз. Доменді `https://` және жолсыз енгізіңіз.
3. Cloud Firestore дерекқорын жасаңыз. Бастапқыда test mode / public access ашпаңыз.
4. Firestore → Rules: `firestore.rules` файлын толық көшіріп, Publish басыңыз. Firebase CLI болса, `firebase deploy --only firestore:rules,firestore:indexes --project ieltsplatform-ee25e` командасын қолдануға болады. Бұл репозиторий ережелері басқа қолданбалармен ортақ дерекқордағы басқа коллекцияларға кіруді жабады; ортақ жоба болса, бар ережелермен біріктіріңіз.
5. Firestore → Indexes: `essays` collection үшін `teacherId` Ascending + `status` Ascending, Collection scope индексін жасаңыз (немесе жоғарыдағы CLI). Индекс дайын болғанша мұғалім тізімі ашылмауы мүмкін.
6. Жалғыз мұғалім аккаунтының UID мәні `src/config.ts` және `firestore.rules` ішінде бекітілген: `GltgUK9bkuZTmVfTi3RhzddrU7X2`. Осы аккаунт кіргенде мұғалім кабинеті бірден ашылады. Қосымша растау, код енгізу немесе мұғалім таңдау жоқ.
7. Оқушы жұмысты жібергенде осы мұғалімге автоматты бағытталады. `teachers` коллекциясы қажет емес.

Firebase провайдерлері мен домендер Firebase Console-да қосылуы керек. Ережелерді өзгерткенде міндетті түрде Firestore-ға жариялаңыз; тек Vercel деплойы дерекқор ережелерін өзгертпейді.

## Беттер және мүмкіндіктер

- `/`: басты бет, оң жақтағы ролик орны, цитата, оқу қадамдары.
- `/lessons`, `/lessons/:id`: 6 толық қазақша сабақ, мысалдар, жаттығулар.
- `/practice`, `/practice/:id`: 6 практика тақырыбы, сүзгі, эссе редакторы, 40 минуттық таймер, сөз санағыш.
- `/register`, `/login`: Google немесе email/password, рөл таңдау, құпиясөзді қалпына келтіру.
- `/dashboard`: оқушының жобалары/жұмыстары немесе мұғалімнің өз оқушылары жіберген жұмыстары.
- `/work/:id`: эссе, 4 критерий бағасы, мұғалім пікірі. Оқушы нәтижені real-time көреді.

Жоба қолмен **Жобаны сақтау** батырмасы арқылы Firestore-да сақталады. Браузер жадында эссе сақталмайды. Бетті жапқанда сақталмаған мәтін туралы браузер ескертуі бар. Басқа бетке өтпес бұрын сақтаңыз. Қонақ мәтін жаза алады, бірақ сақтауға аккаунт қажет; тіркелуге өтпес бұрын мәтінді көшіріп алу ескертіледі. Таймер автоматты жібермейді. Жіберу үшін кемінде 250 сөз керек. Жіберілген эссені оқушы өзгерте алмайды; пікірден кейін жаңа нұсқасын жеке жұмыс ретінде жаза алады.

Мұғалім құқығы тек бекітілген UID арқылы Firestore ережелерінде тексеріледі. Тіркелуде рөл таңдау өздігінен мұғалім рұқсатын бермейді. Мұғалім жіберілген жұмыстарды оқиды және тек баға/пікір өрістерін өзгертеді. Оқушы басқа оқушының эссесін көрмейді және өзін бағалай алмайды.

## Анимациялар

- Пайдаланушының `loading.json` файлы `public/assets/loading.json` ішіне көшірілген. Lottie жүктеу күйлерінде көрсетіледі, reduced-motion параметрін ескереді.
- `public/assets/hero-animation.mp4` — басты бетте GIF сияқты автоматты, дыбыссыз және үздіксіз қайталанып ойнайтын ролик (`autoPlay`, `muted`, `loop`, `playsInline`). Басқару панелі көрсетілмейді.
- `hero-poster.jpg` видео жүктелгенше көрсетіледі. Мобильді құрылғыда ролик бет ішінде ойнатылады.

## Қабылдау тексеруі

1. Оқушы A, оқушы B тіркеледі; жалғыз мұғалім бар аккаунтына кіреді.
2. A 250+ сөздік эссені жоба ретінде сақтайды, бетті жаңартып, жалғастырады.
3. A эссені жібереді; мұғалім кабинетінде жұмыс пайда болады.
4. Мұғалім төрт баға және пікір жібереді; A нәтижені көреді.
5. B осы эссенің URL-ін ашса — қолжетімділік қатесі. Басқа аккаунт «мұғалім» рөлін таңдаса да жұмысты көрмеуі керек.
6. A баға өрістерін немесе рөлін SDK арқылы өзгерте алмауы керек.

Мұғалім бағалары — оқу бағалары; ресми IELTS нәтижесі емес. Google Fonts қолжетімсіз болса, жүйелік Arial шрифті қолданылады.

## Мұғалім материалдарын қосу

Мұғалім кабинетіне кіргенде «Сабақтар» бетінде «Сабақ қосу», «Практика» бетінде «Тапсырма қосу» батырмалары шығады. Жаңа сабаққа бөлімдер, мысалдар және бекіту жаттығуын енгізуге болады. Материалдар Firestore `lessons` және `prompts` коллекцияларында сақталып, бастапқы материалдармен бірге барлық оқушыларға көрсетіледі.

Мұғалім тапсырманы тек қарайды: оған эссе редакторы, сақтау немесе мұғалімге жіберу батырмалары көрсетілмейді. Қосу беттері `/lessons/new` және `/practice/new` тек бекітілген мұғалім аккаунтына қолжетімді. Firestore ережелері де оқушылардың материал қосуына және мұғалімнің оқушы атынан эссе жіберуіне тыйым салады.

**Осы мүмкіндікті қосу үшін жаңартылған `firestore.rules` файлын Firebase Console → Firestore → Rules бөліміне жариялау керек.** Жергілікті CLI аккаунтында бұл жобаға әкімшілік рұқсат жоқ (403), сондықтан production ережелері автоматты жаңартылмады.

## ЖИ анализ — Groq

Хидердегі **ЖИ анализ** (`/ai-analysis`) беті Task 2 сұрағын және эссені қабылдайды. Қазақша толық талдау береді: TR/CC/LR/GRA бойынша болжамды баға, құрылым, нақты үзінділердің түзетулері, сөздік қор, бір абзацтың жақсартылған үлгісі және келесі үш қадам. Баға ресми IELTS нәтижесі емес. Нәтиже мұғалім бағасын өзгертпейді және автоматты түрде дерекқорға сақталмайды. Батырманы басқанда сұрақ пен эссе Groq-қа жіберілетіні интерфейсте көрсетілген.

### Сіз енгізетін жалғыз мән

**Vercel:** Project → Settings → Environment Variables → Name: `GROQ_API_KEY`, Value: Groq кілтіңіз. Қажетті Production/Preview орталарын таңдаңыз да, **Redeploy** жасаңыз. Кілтті `VITE_GROQ_API_KEY` деп атамаңыз: `VITE_` мәндері браузерге жіберіледі. `api/analyze.js` Vercel Node функциясы автоматты жарияланады. Қосымша AI үшін Firebase ережесін өзгерту немесе service-account кілтін қосу қажет емес. Firebase аккаунтпен кіру бұрынғыдай бапталған болуы керек.

**Жергілікті:** жоба түбірінде `.env.local` файлын жасап, мына бір жолды енгізіңіз (үлгі `.env.example` ішінде):

```dotenv
GROQ_API_KEY=your_groq_api_key
```

Содан кейін `npm run dev` серверін қайта іске қосыңыз. Vite-тің жергілікті middleware-і сол `/api/analyze` өңдеушісін қолданады. `npm run preview` тек статикалық нәтижені көрсетеді; ЖИ API үшін `npm run dev` немесе Vercel пайдаланыңыз.

### Қауіпсіздік және шектеулер

- Кілт тек серверде. Клиент Firebase ID token жібереді; сервер Google қолтаңбасын, жоба идентификаторын және token мерзімін тексереді. Тіркелмеген сұраулар қабылданбайды.
- Сұрақ: 10–3000 таңба. Эссе: 50–1500 сөз, ең көбі 15 000 таңба. 250 сөзден аз болса, шектеулі бағалау туралы ескертіледі.
- Модель: `openai/gpt-oss-120b`, Groq strict JSON Schema. Сервер нәтижені қосымша тексереді, болжамды орташа бағаны өзі есептейді; модель көрсеткен бастапқы үзінділердің эсседе бар-жоғын тексереді.
- Бір қолданушыға қатар сұрау жіберуден қорғау және сәтті талдаудан кейін 30 секунд үзіліс бар. Бұл **сервер данасына ғана** қатысты; Vercel бірнеше данамен жұмыс істесе, ортақ тәуліктік лимит емес. Шығын шегін Groq жобасында баптауға болады.
- Провайдердің жауабы 45 секундтан асса тоқтатылады; Vercel функциясының лимиті 60 секунд. Қате, лимит немесе жарамсыз кілт жағдайында мәтін формада қалады. Кілттер, эсселер мен провайдердің толық қате жауаптары сервер журналдарына жазылмайды.
- `.env.local`, `.env` және `.vercel` Git-тен шығарылған. API кілтін репозиторийге немесе интерфейске енгізбеңіз.
